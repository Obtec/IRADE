# IRADE web editor icon

Created with the built-in `image_gen` tool on 2026-11-12, with an opaque background. The selected original is `irade-icon-source.png`. PNG sizes and the multi-resolution ICO are mechanical downscales of that original, generated by `scripts/prepare-icons.py` (Pillow). No CLI image generation was used.

Final prompt:

```text
Use case: logo-brand. Asset type: production web editor app icon and browser favicon for IRADE, a VS Code based collaborative programming and interactive reasoning environment. Create one polished square app icon, not a mockup or presentation. A single bold geometric emblem: two interlocking opposing code angle brackets joined by a shared central vertical stroke, subtly suggesting an abstract I and two collaborators working in one space. Precise, focused, simple silhouette that remains recognizable at 16px. Use the existing code editor visual family: a full-bleed very dark navy square background and a crisp luminous blue/cyan emblem, with strong contrast. Flat graphic, clean solid shapes, balanced generous negative space, emblem entirely within the central 65% safe area so the square can be masked by an operating system. No lettering, no wordmark, no extra symbols, no border, no rounded outer tile, no drop shadows, no 3D, no texture, no watermark. Output a single square raster icon.
```
